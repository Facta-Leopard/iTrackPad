## What iTrackPad requires

- An iPhone running the iPhone build of `iTrackPad`
- A Mac running the Mac build of `iTrackPad`
- Both devices on the same local network
- Accessibility permission on the Mac for cursor, click, drag, and scroll dispatch

## First-time setup

1. Install `iTrackPad` on both iPhone and Mac from the same product listing.
2. Open the Mac build and leave it running.
3. On iPhone, discover the Mac on the local network.
4. Start pairing and enter the same 4-digit code on both devices.
5. Grant Accessibility permission on the Mac when prompted.

## Troubleshooting

### The Mac does not appear on iPhone

- Confirm both devices are on the same local network
- Confirm local network permission was granted
- Confirm the Mac build is running

### Cursor movement does not work

- Open the Mac build of `iTrackPad`
- Check the Accessibility status
- Grant Accessibility access in macOS System Settings if needed

### Pairing fails

- Make sure the same 4-digit code is entered on both devices during the same session
- Remove the trusted device record and try fresh pairing again

### Gestures are received but some desktop actions do not happen

Some advanced desktop-style actions are intentionally left as documented fallbacks when public API, sandbox, or review constraints make a direct system action unsafe or uncertain.

## What to include when contacting support

- iPhone model and OS version
- Mac model and macOS version
- Whether local network permission was granted
- Whether Accessibility permission was granted
- A short description of the issue
